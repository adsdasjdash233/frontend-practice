# 로그인·회원가입·로그아웃 구현 및 파일별 역할 정리

Vite 기반 React 환경에서 localStorage와 react-router-dom을 활용하여 로그인, 회원가입, 로그아웃 기능을 구현한 전체 파일 구조 및 동작 원리를 정리

## 1. 파일 구조

```
src/
├── components/
│   └── Navbar.jsx     # 로그인 상태에 따른 상단 네비게이션
├── pages/
│   ├── Home.jsx       # 메인 홈 페이지
│   ├── Login.jsx      # 로그인 처리 및 스토리지 검증
│   ├── Signup.jsx     # 회원가입 및 스토리지 데이터 저장
│   └── MyPage.jsx     # 로그인 유저 전용 페이지 및 로그아웃
└── App.jsx            # 최상위 상태 관리 및 라우트 접근 제한
```

## 2. 파일별 역할 및 핵심 코드 원리

### 2.1. `src/pages/Signup.jsx` (회원가입)

* **개요:** 사용자로부터 아이디와 비밀번호를 입력받아 데이터를 저장하는 컴포넌트이다.
* **주요 기능 및 특징:**
  * `useState`를 활용해 폼 입력값을 실시간으로 바인딩한다.
  * 별도의 백엔드 데이터베이스가 존재하지 않는 환경이므로 `localStorage.setItem()`을 이용해 브라우저 단에 사용자 정보 객체를 JSON 문자열 형식으로 저장
  * 가입 처리가 완료되면 `useNavigate` 훅의 `navigate('/login')`을 호출하여 로그인 페이지로 사용자를 이동

서버가 따로 없으니까 가입할 때 입력한 아이디랑 비번을 브라우저 저장소(localStorage)에 JSON 문자열로 저장. 이후 가입이 끝나면 useNavigate 을 통해 로그인 페이지(Login.jsx)로 넘김

### 2.2. `src/pages/Login.jsx` (로그인)

* **개요:** 입력된 계정 정보가 기존에 저장된 회원 데이터와 일치하는지 검증하는 컴포넌트
* **주요 기능 및 특징:**
  * `localStorage.getItem('registeredUser')`를 통해 기존에 가입된 회원 데이터를 파싱하여 가져옴.
  * 입력된 아이디/비밀번호와 저장된 값이 일치할 경우 `setIsLoggedIn(true)`를 통해 최상위 로그인 상태를 갱신
  * 새로고침 시에도 로그인 상태가 유지되도록 `localStorage.setItem('isLoggedIn', 'true')` 플래그를 추가로 저장한 뒤 `/mypage`로 이동.

  로컬스토리지에 저장되어 있던 회원 정보를 꺼내와서, 지금 입력한 아이디·비번이랑 똑같은지 비교.
  맞으면 로그인 성공 처리하고, 새로고침해도 안 풀리게 스토리지에 따로 플래그(isLoggedIn) 하나 더 만들고 마이페이지로 이동시켜줌

### 2.3. `src/pages/MyPage.jsx` (마이페이지 & 로그아웃)

* **개요:** 말 그대로 로그인 된 사용자 전용 페이지임.
* **주요 기능 및 특징:**
  * `localStorage`에 저장된 유저 정보를 읽어와 화면 상에 사용자 아이디를 표시한다.
  * 버튼 클릭 시 `setIsLoggedIn(false)`로 상태를 초기화하고 `localStorage`에 저장되어 있던 `isLoggedIn` 플래그를 제거(`removeItem`)한 후 메인 화면으로 리다이렉트한다.

   저장된 유저 정보 가져와서 화면에 아이디 띄워주고, 로그아웃 누르면 로그인 상태 플래그 싹 지운 다음에 홈 화면으로 이동.

### 2.4. `src/components/Navbar.jsx` (네비게이션 바)

* **개요:** 앱 상단에 상시 노출되며, 현재 로그인 상태에 따라 보여줄 메뉴를 전환
* **주요 기능 및 특징:**
  * Props로 전달받은 `isLoggedIn` 값에 따라 삼항 연산자 조건부 렌더링을 수행한다.
  * 비로그인 상태일 때는 `로그인`, `회원가입` 링크를 노출하고, 로그인 상태일 때는 `마이페이지` 링크를 노출한다.

  상단 메뉴바인데 로그인했냐 안 했냐(isLoggedIn)에 따라 보여지는 메뉴가 달라짐 로그인 전이면 로그인/회원가입 보여주고, 로그인 후면 마이페이지 딱 하나만 띄워주는 식

### 2.5. `src/App.jsx` (최상위 상태 관리 및 라우팅)

* **개요:** 전체 애플리케이션의 엔트리 포인트로, 앱이 맨 처음 켜지는 시작점.
* **주요 기능 및 특징:**
  * **새로고침 대응:** `useState` 초기화 함수 내부에서 `localStorage.getItem('isLoggedIn') === 'true'` 조건을 체크하여, 페이지가 새로고침되어도 로그인 상태가 유지되도록 설계되었다.
  * **접근 제한:** 비인증 사용자가 주소창에 `/mypage`를 직접 입력하여 접근을 시도할 경우, 조건부 렌더링(`isLoggedIn ? <MyPage/> : <Navigate to="/login"/>`)을 통해 로그인 페이지로 리다이렉트시킨다.

 여기서 새로고침해도 로그인이 안 풀리게 초기 상태를 로컬스토리지에서 딱 잡아주고, 로그인 안 한 상태에서  /mypage 치고 들어오려고 하면 못 들어오게 튕겨내는 보안(라우트 보호) 역할도 같이 해.
